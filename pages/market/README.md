# 闲置市场功能使用说明

## 功能概述

闲置市场为宝妈们提供了一个安全、便捷的二手母婴用品交易平台，支持物品发布、浏览、详情查看和交易沟通。

## ✅ 已实现功能

### 📱 商品浏览
- **分类筛选** - 支持安全座椅、婴儿车、婴儿床、玩具等8大分类
- **搜索功能** - 按标题和描述搜索商品
- **排序选项** - 默认、价格、距离等多种排序方式
- **商品展示** - 网格布局展示商品图片、价格、卖家信息

### 📝 商品上传
- **完整表单** - 支持标题、价格、分类、成色、使用时间等信息填写
- **图片上传** - 最多支持9张图片，支持拍照和相册选择
- **描述编辑** - 支持详细商品描述（最多500字）
- **表单验证** - 必填项验证，确保信息完整

### 📋 商品详情
- **图片轮播** - 支持多图预览和全屏查看
- **详细信息** - 完整展示商品描述、成色、使用时间等
- **卖家信息** - 显示卖家信誉、评价、回复率等信息
- **互动功能** - 收藏、举报、联系卖家、拨打电话

### 👤 我的发布
- **发布管理** - 查看已发布商品状态
- **数据统计** - 显示浏览量、咨询数、收藏数
- **操作功能** - 支持编辑、刷新、删除商品

### ❤️ 愿望清单
- **收藏功能** - 收藏感兴趣的商品
- **快速访问** - 一键联系收藏商品卖家

## 🎯 使用流程

### 发布商品流程
1. 点击"发布商品"按钮
2. 填写商品基本信息（标题、分类、成色等）
3. 设置价格信息（转让价格、原价）
4. 上传商品图片（1-9张）
5. 撰写详细描述
6. 设置交易地点
7. 提交发布

### 购买商品流程
1. 浏览商品列表，使用筛选和搜索功能
2. 点击感兴趣的商品查看详情
3. 查看商品图片、描述和卖家信息
4. 点击"联系卖家"进行沟通
5. 线下完成交易
