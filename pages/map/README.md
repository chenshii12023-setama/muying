# 地图功能使用说明

## 功能特性

### ✅ 已实现功能
1. **实时定位** - 获取用户当前位置并在地图上显示
2. **周边设施搜索** - 显示用户附近的母婴室、游乐场、医院等设施
3. **地图展示** - 在地图上用不同标记显示设施位置
4. **筛选功能** - 按设施类型筛选（母婴室、游乐场等）
5. **高德地图导航** - 点击设施直接跳转到高德地图导航
6. **交互式地图** - 支持缩放、点击标记查看详情

### 🔧 地图操作
- **📍 定位按钮** - 重新获取当前位置
- **➕ 放大按钮** - 放大地图显示
- **➖ 缩小按钮** - 缩小地图显示
- **📍 设施标记** - 点击标记显示设施选项

### 🎯 使用流程
1. 打开地图页面自动获取位置
2. 地图显示当前位置和周围设施
3. 使用筛选标签查看特定类型设施
4. 点击地图标记或列表中的设施
5. 选择"导航"跳转到高德地图

### 📱 导航方式
- **首选**：高德地图APP导航
- **备用**：微信内置地图导航
- **兜底**：网页版导航链接

## 技术实现

### API集成
- **微信原生地图API** - 用于位置获取和基础地图显示
- **高德地图导航** - 用于专业的路径规划和导航
- **模拟数据** - 当前使用模拟数据，可接入真实POI数据

### 数据来源
- 当前使用模拟设施数据，包含：
  - 母婴室 (🚼)
  - 儿童游乐场 (🎪)
  - 医院 (🏥)
  - 购物中心 (🏬)
  - 亲子餐厅 (🍽️)

### 标记系统
- **绿色标记** - 用户当前位置
- **彩色标记** - 不同类型的设施，用emoji区分

## 故障排除

### 常见问题
1. **定位失败** - 检查位置权限和GPS开关
2. **地图不显示** - 确认网络连接正常
3. **导航无响应** - 检查是否安装高德地图APP
4. **设施数据不准** - 切换到真实POI数据源

### 权限要求
- `getLocation` - 获取用户位置
- `chooseLocation` - 选择位置
- `chooseAddress` - 选择地址
