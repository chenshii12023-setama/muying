# 图片资源目录

此目录用于存放小程序所需的图片资源。

## 必要的图片文件：

- `default-avatar.png` - 默认用户头像
- `wechat-avatar.png` - 微信用户头像
- `growth-icon.png` - 成长记录图标
- `market-icon.png` - 闲置市场图标
- `favorite-icon.png` - 收藏图标
- `baby-icon.png` - 宝宝相关图标
- `map-icon.png` - 地图资源图标
- `growth-icon.png` - 成长评估图标

## 建议的图片规格：

- 图标：建议使用 100x100px 或 200x200px 的PNG格式
- 头像：建议使用 150x150px 的圆形PNG格式
- 背景图：根据实际需要调整尺寸

请在微信小程序开发者工具中导入这些图片资源。
