# 宝妈育儿轻指南 - 微信小程序

一个专为宝妈设计的育儿助手小程序，集成了宝宝成长记录、资源地图、闲置置换、AI智能助手等实用功能。

## 🎯 项目特色

- **温馨的设计风格** - 采用柔和的粉色系配色，营造温暖的育儿氛围
- **全面的功能覆盖** - 从成长记录到资源查找，一站式满足育儿需求
- **AI智能助手** - 内置智能问答和辅食营养计算功能
- **安全可靠** - 特别注重婴幼儿用品交易的安全保障

## 📱 功能模块

### 1. 首页
- 今日天气和宝宝成长统计
- 快捷功能入口
- 最新育儿资讯

### 2. 宝宝成长记录
- 身高体重曲线记录
- 发育里程碑管理
- 成长海报生成

### 3. 资源地图
- 附近母婴室位置
- 儿童游乐区查询
- 用户上传新地点

### 4. 闲置置换市场
- 母婴用品交易平台
- 同城自提功能
- 消毒证明上传

### 5. AI智能助手
- 育儿问题智能问答
- 辅食营养计算器
- 个性化喂养建议

### 6. 个人中心
- 用户信息管理
- 成长记录统计
- 设置和帮助

## 🛠 技术栈

- **前端框架**: 微信小程序原生开发
- **UI组件库**: TDesign for MiniProgram
- **状态管理**: 小程序原生数据绑定
- **存储方案**: 本地存储 + 模拟数据

## 🚀 快速开始

### 1. 环境准备

- 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 申请微信小程序 AppID

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择项目根目录
4. 输入 AppID（可使用测试号）

### 3. 安装依赖

```bash
npm install
```

### 4. 构建项目

在微信开发者工具中点击"构建npm"

### 5. 预览和发布

- 点击"预览"在手机上查看效果
- 点击"上传"发布到小程序后台

## 🔧 开发说明

### 数据模拟
当前版本使用本地存储模拟数据，正式环境需要接入后端API：

```javascript
// 替换模拟数据调用
// 当前: wx.getStorageSync('growthRecords')
// 正式: app.request({ url: '/api/growth-records' })
```

### 权限配置
小程序需要配置以下权限：
- 用户信息获取
- 地理位置获取
- 相册和相机访问

### 组件使用
项目使用 TDesign 组件库，使用前需要：

1. 在页面 json 中引入组件
2. 在 wxml 中使用组件

```json
{
  "usingComponents": {
    "t-button": "tdesign-miniprogram/button/button"
  }
}
```
